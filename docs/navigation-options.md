# Sidebar options to explore later

The live sidebar has not been changed for this request.

| Direction | What it would look like | Tradeoff |
| --- | --- | --- |
| Refined grouped sidebar | Keep the current labeled navigation; tighten the primary group around Home, People, Events and Follow-ups. Keep Scan and My QR prominent. | Clearest starting point for new users. |
| Expandable icon rail | A narrow rail on desktop, with labels shown when expanded and accessible tooltips when collapsed. | Gives contacts/maps more room, but unfamiliar icons need labels. |
| Event-first navigation | Current event at the top, followed by people and follow-ups for that event, with a clear route back to the full contact book. | Useful during a conference; needs care for people attending several events. |

My preferred next experiment is the **expandable desktop rail** with labeled navigation as its default. Mobile should keep the existing scan-centered bottom navigation. These are directions to compare, not changes to the current app.
